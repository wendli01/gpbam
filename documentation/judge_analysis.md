# Judge analysis

## Question

### Why does the essay-level n vary between judge pairs?

The essay-level analysis uses pairwise-complete observations. An essay is used
for a particular judge pair only when both judges have a numeric score for that
essay. It is not necessary for the third judge to have a score.

For the current no-retrieval analysis, four generation models are excluded:

- mistral-small-3.1-24b-instruct
- EuroLLM-22B-Instruct-2512
- Phi-4-mini-instruct
- gemma-4-31B-it-FP8-block

This leaves 26 generation models, each with 81 essays:

\[
26 \times 81 = 2{,}106 \text{ essays.}
\]

The verified score availability after those exclusions is:

| Judge | Available scores | Missing scores |
|---|---:|---:|
| gpt-5-nano | 2,101 | 5 |
| DeepSeek-V4-Flash | 2,104 | 2 |
| qwen3.6-35b-a3b | 2,105 | 1 |

The missing rows do not overlap between these judges. Consequently:

| Judge pair | Calculation | Pairwise n |
|---|---:|---:|
| gpt-5-nano / DeepSeek-V4-Flash | 2,106 - 5 - 2 | 2,099 |
| gpt-5-nano / qwen3.6-35b-a3b | 2,106 - 5 - 1 | 2,100 |
| DeepSeek-V4-Flash / qwen3.6-35b-a3b | 2,106 - 2 - 1 | 2,103 |

The implementation performs this operation separately for every judge pair:

    paired = scores[[judge_a, judge_b]].dropna()
    n = len(paired)

A missing score is represented as NaN. It can arise from an empty judge
response, a judge/API failure, or a response from which the scoring expression
could not extract a numeric score. The correlation analysis does not replace or
impute such a value, because doing so would manufacture judge agreement or
disagreement. Instead, only that judge pair loses that essay.

The returned analysis exposes the relevant diagnostics:

    agreement["essay"]["availability"]

The combined table also includes n_total and n_missing for each judge pair.

### What does “essay-level confidence intervals resample complete generation-model clusters” mean?

The approximately 2,100 essay rows are not approximately 2,100 independent
experimental units. Essays produced by the same generation model share model
architecture, training, prompting behaviour, response style, typical length,
and systematic strengths and weaknesses. Scores for two essays from the same
model can therefore be more similar than scores for essays from unrelated
models.

A naive bootstrap would sample individual essays with replacement and treat all
essay rows as independent. That would break the within-model grouping and would
usually make the confidence interval too narrow.

The implemented cluster bootstrap instead works as follows for each judge pair
and agreement method:

1. Start with the generation-model clusters remaining after exclusions, 26 in
   the current analysis.
2. Draw 26 model identifiers with replacement.
3. For every selected identifier, include all pairwise-complete essays from that
   generation model.
4. Recalculate Spearman, Pearson, or QWK on the resulting pooled essay sample.
5. Repeat this process n_boot times, 10,000 by default.
6. Use the 2.5th and 97.5th percentiles of the bootstrap coefficients as ci_low
   and ci_high.

If a model is sampled twice, its complete essay block appears twice in that
bootstrap replicate. If it is not sampled, none of its essays appears. This
preserves dependence among essays generated by the same model while estimating
uncertainty in the pooled essay-level coefficient.

Concretely, one generation model is treated as one cluster containing its 81
case answers. When that model is selected during bootstrap resampling, the
entire block is selected at once: all 81 answers enter the replicate together.
The 81 answers are not sampled independently. Conversely, if the model is not
selected, its entire block of 81 answers is absent from that replicate. Because
sampling is with replacement, a model can be selected more than once; in that
case its entire answer block is repeated once for every selection.

The effective cluster size is specific to the judge pair. Missing scores are
removed pairwise before resampling, so a model normally contributes 81 essays
but can contribute 80 or fewer if either judge in that pair is missing a score.
The bootstrap still moves all remaining pairwise-complete essays for that model
together as a single cluster.

This procedure has an important limitation: the data are crossed as well as
clustered. The same GPBam case is answered by multiple generation models, so
there may also be dependence among answers to the same case. The implemented
bootstrap accounts for generation-model clustering, but it does not also
resample or model the shared-case effect. A formal analysis targeting both
sources of dependence would require a crossed-effects model or a carefully
specified two-way bootstrap.

## Documentation

### Purpose

[judge_correlation_codex.py](../src/notebook_eval/judge_correlation_codex.py)
measures agreement among the three LLM judges used to evaluate GPBam legal
essays. It supports model-level and essay-level analysis, three complementary
agreement measures, bootstrap confidence intervals, method-appropriate
p-values, a combined result table, LaTeX output, and a two-panel agreement
figure.

The three measures answer related but different questions:

| Measure | Primary question | Important property |
|---|---|---|
| Spearman rho | Do the judges rank observations similarly? | Uses ranks and is insensitive to monotone rescaling. |
| Pearson r | Do the judges’ scores have a strong linear relationship? | Sensitive to linear association, but not to a constant scoring-level shift. |
| Quadratic-weighted kappa, QWK | Do the judges assign similar absolute ordinal scores? | Penalises absolute disagreement more strongly as score distance increases. |

This distinction is essential. Two judges can have high Spearman and Pearson
coefficients because they order models similarly while having a much lower QWK
because one judge is systematically stricter.

### Data preparation

The function identifies every column beginning with score_Judge and converts
the values to numeric form. Unparseable or absent values become NaN.

The experiment contains two Qwen judge columns corresponding to mutually
exclusive FP8 and API endpoints. They are fallback executions of one logical
judge rather than two separate raters. The code coalesces them row by row into
one qwen3.6-35b-a3b column before any averaging, correlation, token counting, or
missingness calculation.

Generation-model names are shortened to the component after the final slash.
Names supplied through exclude are validated; an unknown exclusion raises
instead of silently doing nothing.

### Model level and essay level

At model level, the score supplied by judge \(j\) for generation model \(m\) is
the arithmetic mean of that judge's available case scores:

$$
\bar{s}_{mj} = \frac{1}{N_{mj}}\sum_i s_{mji}.
$$

Each generation model is then one observation. A judge-pair coefficient is
computed across the vectors of model means. This level answers whether the
judges agree about the comparative performance of generation models. It is the
primary level for claims such as “the judges rank models similarly.”

At essay level, no model-level averaging is performed. Each row is one generated
essay for one GPBam case, and the two scores assigned to that same essay form a
paired observation. The coefficient is computed over all pairwise-complete
essays. This level answers whether the judges score individual answers
similarly.

The essay-level coefficient is pooled. It combines:

- between-model differences in average answer quality;
- between-case differences in difficulty;
- within-model, between-essay variation;
- judge-specific differences in ranking and score calibration.

It is therefore complementary to, not a replacement for, the model-level
coefficient.

### Why scores are represented as percentages for QWK

The stored judge scores lie on 0--1. The observed essay scores mainly use 0.05
or 0.10 increments. Spearman and Pearson can use these numeric values directly.
QWK, however, is defined for ordered categories and needs a fixed ordinal grid.

The analysis first scales all judge scores by the scale argument, which defaults
to 100. For QWK, it then maps the bounded score to qwk_categories ordered
labels. The default is 101 labels, 0 through 100:

$$
\ell(s)=\operatorname{round}\left(
\frac{\operatorname{clip}(s,0,100)}{100}\times100
\right).
$$

This representation was chosen for four reasons:

1. It supplies the discrete ordered categories required by QWK.
2. It preserves the original 0.05 and 0.10 essay-score increments exactly as
   5-point and 10-point differences.
3. It uses the same fixed scale for essay scores and model-level mean scores.
4. It rounds model-level means only to the nearest percentage point, avoiding
   the substantial information loss that would result from decile bins.

Changing from 0--1 to 0--100 is a positive linear rescaling and does not by
itself change quadratic-weighted kappa when category distances are preserved.
The material operation is discretisation onto a declared fixed grid. The
implementation's QWK value was numerically verified against
scikit-learn.metrics.cohen_kappa_score with weights="quadratic" and labels
0 through 100.

QWK is most natural at essay level, where judges directly assign ordinal scores
to the same item. At model level it is a secondary, calibration-sensitive
summary of agreement between discretised judge means.

### How QWK is calculated

QWK compares observed squared disagreement with the disagreement expected if
the two judges' ordinal score distributions were paired independently:

$$
\kappa_w = 1 -
\frac{\text{observed quadratic disagreement}}
     {\text{expected quadratic disagreement}}.
$$

The code uses an algebraically equivalent moment calculation instead of
constructing a 101 by 101 disagreement matrix for every bootstrap and
permutation replicate. This is substantially faster and produced the same
values as the standard scikit-learn implementation to machine precision.

Interpretation follows the usual direction:

- 1 means perfect agreement;
- 0 means no improvement over agreement expected from the marginal score
  distributions;
- negative values indicate worse agreement than that expectation.

QWK is not directly interchangeable with a correlation coefficient. Its lower
value can be substantive evidence of different judge severity rather than a
contradiction of high rank correlation.

### Pairwise-complete observations and n

Every judge pair is analysed separately after dropping rows on which either
member of that pair is missing. Consequently, n can differ between pairs.
Neither a complete-case requirement across all three judges nor score
imputation is used.

The combined result table includes:

- n: number of pairwise-complete observations actually used;
- n_total: number of observations before pairwise missing-score removal;
- n_missing: n_total minus n;
- n_clusters: number of generation-model clusters represented. At model level
  this equals the number of model observations; at essay level it reports the
  model clusters used by the cluster bootstrap.

The availability table returned separately reports n_total, n_available, and
n_missing for each individual judge.

### Confidence intervals

All three methods receive separate percentile 95% bootstrap confidence
intervals.

At model level:

1. Pairwise-complete generation models are sampled with replacement.
2. The selected coefficient is recalculated.
3. The process is repeated n_boot times.

At essay level, generation-model clusters rather than individual essays are
sampled with replacement, as described in the Question section.

For both levels:
 
$$
\mathrm{CI}_{\mathrm{low}}
= Q_{0.025}\!\left(\hat{\theta}^{*}\right),
\qquad
\mathrm{CI}_{\mathrm{high}}
= Q_{0.975}\!\left(\hat{\theta}^{*}\right).
$$




where $\hat{\theta}^{*}$ is a bootstrap coefficient and $Q$ denotes an
empirical quantile. Degenerate replicates in which either resampled score vector
has fewer than two distinct values are skipped. The seed argument makes the
resampling reproducible. The default n_boot is 10,000.

The intervals are calculated independently for each judge pair and method.
Using the same deterministic seed offset for methods within a pair keeps their
resampling schemes comparable.

### P-values and p_value_type

The p_value_type column states which inferential procedure produced p_value:

| p_value_type | Where used | Calculation and interpretation |
|---|---|---|
| analytic | Model-level Spearman and Pearson | Two-sided p-value returned by scipy.stats.spearmanr or scipy.stats.pearsonr under the standard observation-level assumptions. |
| permutation (B) | Model-level QWK | One judge's model scores are randomly permuted B times, QWK is recalculated, and a two-sided plus-one corrected p-value is computed. |
| not reported (clustered essays) | Every essay-level method | p_value is NaN because the ordinary test would incorrectly treat essays as independent. |
| not available | Any degenerate pair | The pair has too few observations or too little variation to calculate the coefficient. |

For model-level QWK, the implemented permutation p-value is:

$$
p =
\frac{1 + \#\{|\kappa_w^{*}|\geq|\kappa_w^{obs}|\}}
     {B+1}.
$$

The plus-one correction prevents a reported p-value of exactly zero. With
10,000 permutations, the smallest attainable value is \(1/10{,}001\).

### Why essay-level ordinary p-values are omitted

The ordinary Spearman and Pearson tests assume that the paired observations are
independent. An ordinary QWK permutation test likewise assumes that individual
pairings can be permuted exchangeably. Those assumptions do not hold for essays
nested within generation models.

If approximately 2,100 essays were treated as independent, the nominal sample
size would greatly overstate the amount of independent information and would
usually produce p-values that are much too small. Reporting such values would
look precise but would be statistically misleading.

The analysis therefore reports:

- the pooled essay-level coefficient;
- a generation-model cluster-bootstrap confidence interval;
- no ordinary essay-level p-value.

The confidence interval still communicates the estimated magnitude and its
uncertainty under the implemented cluster-resampling scheme. A formal
hypothesis test accounting simultaneously for generation-model and shared-case
effects would require a different inferential model and is not fabricated by
this utility.

### Meaning of each statistical-treatment choice

**Model-level means.** These make the generation model the observational unit,
which matches claims about model rankings and prevents a model with more valid
essay rows from automatically receiving more weight.

**Essay-level pooled scores.** These address direct agreement on individual
answers and retain within-model variation that averaging removes.

**Spearman and Pearson together.** Spearman captures rank agreement and is
robust to monotone score transformations. Pearson detects linear association.
Comparing them helps distinguish ranking from linear calibration.

**QWK in addition to correlation.** Correlation can remain high when one judge
is consistently harsher. QWK penalises absolute score differences and therefore
tests a stricter notion of agreement.

**Model-level bootstrap by model.** Models are the observations at this level,
so they are the units that must be resampled.

**Essay-level bootstrap by generation-model cluster.** This preserves
within-model dependence and avoids treating every essay as independent.

**Analytic p-values for model-level correlations.** Standard two-sided tests
exist for Spearman and Pearson when models are treated as the observations.

**Permutation p-value for model-level QWK.** There is no single analytic QWK
p-value used by this analysis, so permutation supplies a direct null
distribution while preserving each judge's marginal score distribution.

**Omitted essay-level p-values.** The ordinary tests are invalid under the
known clustering. Omitting them is preferable to reporting anti-conservative
values.

**Pairwise deletion rather than imputation.** The analysis uses only scores
actually supplied by both judges. It does not invent scores for failed or
unparseable judgments.

### Returned objects and table columns

The recommended entry point is:

    agreement = judge_correlation_codex.analyze_levels(
        model_study_df,
        methods=["spearman", "pearson", "qwk"],
        n_boot=10_000,
        n_permutations=10_000,
        seed=42,
        exclude={
            "mistral-small-3.1-24b-instruct",
            "EuroLLM-22B-Instruct-2512",
            "Phi-4-mini-instruct",
            "gemma-4-31B-it-FP8-block",
        },
    )

It returns:

- agreement["model"]: complete model-level analysis;
- agreement["essay"]: complete essay-level analysis;
- agreement["table"]: one tidy table containing both levels, all judge pairs,
  and all requested methods.

The combined table columns are:

| Column | Meaning |
|---|---|
| level | model or essay |
| judge_a, judge_b | Pair of logical judges |
| n | Pairwise-complete observations used |
| n_total | Observations before pairwise deletion |
| n_missing | Observations removed for this pair |
| n_clusters | Generation-model clusters represented |
| method | spearman, pearson, or qwk |
| coefficient | Agreement estimate |
| ci_low, ci_high | Percentile 95% bootstrap interval |
| p_value | Method-appropriate p-value, or NaN when intentionally omitted |
| p_value_type | Procedure used for p_value |

### LaTeX table

The LaTeX exporter consumes the combined table:

    table_latex = judge_correlation_codex.agreement_table_to_latex(
        agreement["table"],
        label="tab:judge_agreement_without_rag",
    )

The default caption is standalone: it defines both levels, all three measures,
the QWK scale, confidence-interval resampling, p-value procedures, pairwise n,
and Qwen coalescing. Pass caption=... to replace it. The generated table uses
the booktabs commands top rule, mid rule, bottom rule, and add linespace, so the
LaTeX document must load the booktabs package.

### Agreement figure and figure caption

The recommended figure is a two-panel coefficient forest plot:

    fig, axes = judge_correlation_codex.plot_level_agreement(
        agreement,
        methods=["spearman", "pearson", "qwk"],
        save_path="judge_agreement_codex.pdf",
        dpi=300,
    )

The left panel reports model-level estimates; the right panel reports
essay-level estimates. Each judge pair is a row, methods use different markers
and colours, and horizontal bars display the method-specific bootstrap
intervals. This design is preferable to a heatmap for the main result because
it shows both coefficient magnitude and uncertainty and makes the stricter QWK
values directly comparable with Spearman and Pearson.

Generate a LaTeX figure wrapper with the standalone default caption:

    figure_latex = judge_correlation_codex.agreement_figure_to_latex(
        "judge_agreement_codex.pdf",
        label="fig:judge_agreement_without_rag",
    )

The LaTeX document must load graphicx for includegraphics. The default figure
caption defines the panels, methods, confidence intervals, clustering,
pairwise-complete essay counts, QWK grid, and Qwen coalescing. It can be
overridden with caption=....

### Interpretation and limitations

The analysis should not label a high correlation as high absolute agreement
without examining QWK. In the current data, some judge pairs show very high
Spearman and Pearson values but much lower QWK, indicating similar ordering
alongside systematic differences in score severity.

Important limitations are:

- Essay-level cluster intervals account for generation-model clustering but not
  shared-case clustering across models.
- Complete-case analysis assumes the small amount of score missingness is not
  strongly informative. The missing rows are reported rather than hidden.
- Model-level inference is conditional on the included set of generation models
  and the shared GPBam case set.
- Model-level QWK requires discretising judge means; the 101-category grid makes
  this discretisation fine-grained and explicit.
- The utility does not apply a multiple-testing correction across judge pairs
  and methods. If p-values are used for formal simultaneous claims, the
  correction procedure should be declared separately.
- Bootstrap intervals and p-values answer different inferential questions and
  need not lead to numerically identical threshold decisions.
